B站首页模型评测 — Windows 使用说明

一、直接查看评测榜单

双击根目录下的“打开评测榜单.bat”，或直接打开 evaluation\index.html。
这部分不需要安装 Node.js，也不需要安装任何依赖。

二、运行单个模型作品

压缩包已排除所有 node_modules 和本地缓存。需要运行某个作品时：

1. 安装 Node.js 20 或更高版本。
2. 进入 one-shot 或 adversarial 下对应的模型目录。
3. 查看该目录的 package.json 和项目说明。
4. 通常先运行 npm install，再运行 npm run dev 或 npm start。

不同作品使用的前端框架和启动命令不完全相同，请以各自的 package.json 为准。
建议同一时间只启动一个作品，避免端口冲突。

三、关于统一实机导演台

evaluation 下的统一导演台包含批量启动、停止和切换作品的进程管理逻辑，当前版本按 macOS/Linux 环境制作，不能保证在原生 Windows 中正常管理全部作品。

在 Windows 中可以直接使用静态评测榜单。若需要逐个操作作品，可按上一节手动启动；若要使用完整统一导演台，建议在 WSL2 环境运行。

四、压缩包内容

- one-shot：一次性指令直出的 10 个作品
- adversarial：对抗性审查多轮结果的 10 个作品
- evaluation：评测数据、榜单、导演台和相关素材
- 项目根目录中的实验说明与启动文档

本包不包含 node_modules、Git 元数据、缓存、日志、环境变量文件、密钥文件和其他压缩包。
