# 盲评截图素材

这是用于独立视觉评审的匿名截图包。每个 `S01` 到 `S20` 目录代表一个成品样本，但目录名不对应模型名称或开发模式。

每个目录只包含四张同名截图：

- `home.png`：首页首屏
- `feed.png`：首页向下浏览一屏
- `search-results.png`：搜索结果状态
- `video.png`：视频详情页状态

请只依据画面本身进行观察和记录，使用 `S01` 至 `S20` 作为样本编号。截图保持原始采集状态；如果出现错误页、重复页、空状态或图片缺失，请按实际看到的内容记录，不要修饰、补全或猜测原因。

请不要改名、移动或覆盖素材。评审记录应放在本目录之外；本目录不包含模型身份映射。
