# bilibili 首页复刻（演示项目）

本项目是一个可运行的哔哩哔哩首页复刻：前端 Vue 3 单页应用提供首页视频流、视频详情播放、搜索、分类筛选与头部菜单等交互；后端 Node.js/Express 提供数据 API 与媒体文件服务。数据来自 2026-09-12 抓取的 B 站公开排行榜快照（510 条真实视频元数据、真实封面与 UP 主头像），本地自包含，启动后不依赖 B 站在线接口。

## 端口约定

端口在三处保持一致：前端启动参数 `frontend/package.json` 与 `frontend/vite.config.js`、后端监听 `backend/server.js`、本 README。

| 服务 | 端口 | 启动来源 |
| --- | --- | --- |
| 前端 Vite 开发服务器 | 3802 | `frontend/package.json` 的 `dev` 脚本，`--port 3802 --strictPort` |
| 后端 Express API | 5802 | `backend/server.js` 中 `app.listen(5802)` |

前端通过 Vite 代理把 `/api` 与 `/media` 转发到 5802，浏览器只需要访问 3802 一个地址。两个端口都被占用时 Vite 会直接报错退出（strictPort），需要先释放端口再启动，不做自动换端口。

## 技术栈与分层

- 前端：Vue 3（组合式 API）+ Vue Router 4 + Pinia 2 + Vite 5。状态分两层：服务端数据放在视图组件内按需请求；用户本地状态（观看历史、稍后再看、收藏、点赞投币、关注、搜索历史、本地评论）放在 Pinia store `frontend/src/stores/user.js`，持久化到 localStorage。
- 后端：Node 22 + Express 4。`backend/server.js` 负责路由，数据快照一次性载入内存。
- 数据层：`backend/data/videos.json` 是唯一数据源，由抓取脚本生成；`backend/public/` 存放媒体文件（封面、头像、可播放示例视频），由 Express 静态服务对外提供。

## 快速开始

前置条件：Node.js 18 以上（开发环境为 22.22.2），npm 可用，能访问 npm registry。`backend/data/videos.json` 与媒体文件已随项目提供，无需重新抓取即可启动。

1. 安装依赖。在项目根目录执行 `npm run setup`。该命令依次安装根、backend、frontend 三处依赖。预期结果：三条 npm install 均无 error 退出。
2. 启动服务。执行 `npm run dev`。该命令用 concurrently 同时启动后端（5802）与前端（3802）。预期结果：日志出现 `bili-clone-backend http://localhost:5802` 与 `VITE ready`、`Local: http://localhost:3802/`。
3. 验证后端。执行 `curl http://localhost:5802/api/health`。预期返回 `{"ok":true,"port":5802,"videos":510,...}`。
4. 验证前端与代理。浏览器打开 `http://localhost:3802/`，应看到顶部导航、分类条与视频卡片流；执行 `curl -I http://localhost:3802/media/videos/bbb-1080.mp4` 应返回 206 或 200。
5. 停止服务：在运行 `npm run dev` 的终端按 Ctrl+C。

测试与构建：

- 执行 `npm test` 运行全部自动化测试。后端用 Node 内置 node:test（`backend/test/api.test.mjs`，9 个用例：健康检查、推荐流 510 条分页无重复遍历、分类过滤完整性、详情与相关推荐、404、建议、搜索命中校验、排行榜排序、分类清单），前端用 vitest（`frontend/src/stores/user.test.js`，7 个用例：历史去重与上限、稍后再看/收藏 toggle、点赞投币关注、localStorage 持久化往返、搜索历史、本地评论）。2026-09-12 实测 9+7 全部通过。
- 执行 `npm run build` 构建前端生产包到 `frontend/dist`。2026-09-12 实测构建成功。

如需重建数据快照（可选，正常使用不需要）：执行 `npm run fetch:data`。脚本会重新拉取 B 站各分区排行榜并下载封面、头像与示例视频，已存在的文件自动跳过。

## 功能与交互

以下每一条都在 2026-09-12 的浏览器端到端自检中执行过，证据截图见文末。

- 首页视频流：推荐流按全站热榜顺序分页加载，滚动到底部自动加载下一页（每页 30 条，共 510 条）；加载中有骨架屏，加载完显示到底提示。
- 卡片 hover：鼠标悬停后封面右上角出现"稍后再看"与"不感兴趣"两个按钮，左下角出现播放量与弹幕数浮层；悬停约 0.5 秒后浮层隐藏、卡片内开始静音循环播放该视频片段（与 B 站预览行为一致）。点"稍后再看"写入本地稍后再看列表，点"不感兴趣"把该卡片从当前流里移除；离开首页（keep-alive 切到详情页）时预览自动停止。
- 分类筛选：首页顶部分类条含推荐、热门与 8 个内容分区；顶部"分区"按钮悬停展开大菜单，共 19 个入口（推荐、热门两个聚合分类加 17 个内容分区）。点击后 URL 同步为 `/?category=xxx`，列表整体切换，支持刷新后保持；上一分类滚动到底后切换新分类，无限滚动会继续工作直到新分类全部加载完。
- 搜索建议：搜索框聚焦时展示热搜榜（按播放量取前 10）与本地搜索历史；输入时按标题、UP 主名、子分区名做子串联想，命中词高亮，支持键盘上下键选择与回车搜索，历史可单条删除。联想请求带序号守卫，慢的旧响应晚到会被丢弃。
- 搜索结果页：全部/视频/UP主三个筛选页签均有效（"全部"同时展示视频与相关 UP 主，"UP主"只展示 UP 主行，点击 UP 主跳转搜索其名字）；换搜索词自动回到"全部"页签。结果为横排条目（封面 + 标题关键词高亮 + UP 主 + 播放/弹幕 + 日期 + 分区标签），支持加载更多与空结果提示；请求失败显示错误提示与重试按钮。
- 视频详情与真实播放：点击卡片或相关推荐进入 `/video/:bvid`；播放器为本地 MP4 真实播放（支持进度拖动、音量、倍速、全屏），顶部有弹幕栏：弹幕按时间轴飘过、可输入发送自己的弹幕（暂停时发送的弹幕在恢复播放后展示）、可整体开关（关闭期间路过的弹幕不会在重开后补发）。页面包含标题、分区面包屑、UP 主卡片（关注/发消息）、点赞/投币/收藏/分享（投币有 1/2 枚弹窗，计数会并入本地已有的互动增量）、简介展开、评论区（最热/最新排序、发布本地评论、点赞）。连续快速跳转相关视频时只提交最后一次请求的结果与观看历史，旧响应被丢弃；离开详情页恢复浏览器默认标题。
- 相关推荐与返回首页：详情页右侧 12 条相关推荐可继续跳转；点头部 logo、"首页"导航或浏览器返回键回到首页，首页信息流通过 keep-alive 保留，无需重新加载。
- 头部菜单展开：头像菜单、消息、动态、收藏（含稍后再看/收藏两个分组，数据为本地真实记录）、历史（真实观看记录）、创作中心均为悬停展开面板；"投稿"与未收录频道点击给出提示反馈。

## API 一览

| 方法与路径 | 参数 | 返回要点 |
| --- | --- | --- |
| GET /api/health | 无 | `{ok, port:5802, videos:510, fetchedAt}` |
| GET /api/categories | 无 | `chips`（首页分类条）与 `menu`（大菜单分区）两组 key/label |
| GET /api/feed | category、page、pagesize | 视频卡片列表，`hasMore` 标记是否还有下一页 |
| GET /api/video/:bvid | 无 | 视频详情、12 条相关推荐、20 条合成评论、30 条弹幕池、评论总数 |
| GET /api/suggest | q | q 为空返回热搜榜；非空返回子串联想前 10 |
| GET /api/search | q、page | 命中视频列表与总数（匹配标题、UP 主、子分区、分区名） |
| GET /api/rank | category | 按点赞数取前 10 的排行榜 |
| GET /media/* | 无 | 封面、头像、示例视频静态文件，视频支持 Range 分段请求 |

## 数据来源

- 视频元数据：B 站公开接口 `/x/web-interface/ranking/v2`，2026-09-12 抓取 17 个分区各前 30 条，去重后 510 条（番剧分区该接口返回为空，已跳过）。标题、封面、UP 主、播放/弹幕/点赞等数据均为真实数据。
- 封面与头像：从 hdslb.com CDN 下载，利用 CDN 缩放参数压成 480w/120w 的 webp，本地存放，运行时不再访问 B 站。
- 可播放视频：B 站正片流需要登录态与签名，不做破解。每个视频按 bvid 哈希映射到 7 段公开授权片段之一（Blender 开放电影预告片与 CC0 示例片段，共 33MB，单片时长分别约为 5 秒、10 秒、10 秒、10 秒、33 秒、52 秒、300 秒），因此详情页的真实时长（如 2:11:55）与实际播放片段时长不一致，这是有意为之的演示取舍。

## 简化项

- 无账号体系：所有用户行为（历史、收藏、点赞、投币、关注、评论）保存在浏览器 localStorage，仅本机可见；头像、硬币余额、粉丝数为演示合成数据。
- 评论与弹幕：评论列表由服务端按视频确定性合成（B 站评论接口需登录态），用户自己发布的评论保存在本地；弹幕为本地合成池加用户发送，非 B 站真实弹幕。
- 播放源映射：见上文"数据来源"第三条。
- 导航入口：直播、会员购、漫画、赛事、下载客户端等频道无对应数据，点击给出"演示站未收录"提示；番剧入口跳转到动画分区。
- 排行榜"今日/三日"两个页签基于同一份快照分别按播放量与点赞数排序，非真实分时段榜单。
