## 主链路实际断言

1. 首页取得 20 张视频卡片，切换轮播，加载后得到 24 张；美食筛选只剩 2 张。
2. 输入“猫咪”，选择后端返回的建议，点击搜索结果进入详情。
3. 详情出现带 controls 的真实 MP4 播放器；收藏写入 localStorage；评论与弹幕显示；返回首页后历史弹窗包含刚才的视频。
4. 空搜索可恢复推荐；悬停游戏菜单并点击“游戏推荐”后只显示 1 个游戏视频。
5. 不存在的视频显示 404 提示与首页链接；昵称可保存；收藏可取消；播放器 error 事件显示重试按钮。
